# All in One Edition original mini-games

`originals.html` contains ten original, self-contained browser game implementations used by the main catalogue:

- Snake Sprint
- Memory Match
- Reaction Rush
- Brick Breaker
- Tic-Tac-Toe
- Paddle Pong
- Minefield Logic
- Sliding 15
- Simon Sequence
- Word Scramble

## Reuse and assets

These implementations were written for this repository rather than copied from a game portal or another repository. They use inline HTML, CSS, JavaScript, the browser Canvas API where needed, system fonts, and native emoji glyphs. No third-party game framework, image pack, music track, or remote runtime is loaded by this file. Emoji appearance depends on the user's operating system/browser.

The catalogue continues to contain older third-party game links and embeds. Those games remain the property of their respective creators; this change does not rehost their files or claim authorship of them. Provider metadata in the catalogue is internal integration data and is not rendered as a source label on game cards.

## Controls

- Snake Sprint: arrow keys/WASD, plus on-screen directional controls.
- Memory Match: click/tap cards.
- Reaction Rush: tap to start, then tap when the panel turns green.
- Brick Breaker: left/right arrows or A/D, or move the pointer over the canvas.
- Tic-Tac-Toe: local two-player click/tap.
- Paddle Pong: W/S or up/down arrows; the opponent paddle uses simple local AI.
- Minefield Logic: click/tap to reveal; right-click or Flag mode to mark mines.
- Sliding 15: click/tap a tile next to the empty space.
- Simon Sequence: repeat the displayed colour sequence.
- Word Scramble: enter the word and submit or press Enter.

All games are loaded only when the selected game card is launched.
